БОТ v7 — ФИЛЬТРЫ КАЧЕСТВА МОНЕТ + ПОДТВЕРЖДЕНИЕ 3 ЗЕЛЁНЫХ СВЕЧЕЙ
======================================================================

Добавлены три новых фильтра (все настраиваются константами в начале файла):

1. МИНИМАЛЬНЫЙ ОБОРОТ 24Ч — MIN_TURNOVER_24H = 30_000_000
   Функция universe() теперь отсекает монеты с оборотом за 24ч
   меньше 30 млн $ ЕЩЁ ДО сканирования — такие монеты вообще
   не попадают в цикл проверки сигналов.

2. МИНИМАЛЬНЫЙ ВОЗРАСТ ЛИСТИНГА — MIN_LISTING_AGE_DAYS = 182 (полгода)
   Новая функция listing_age_days(symbol) определяет возраст монеты
   на Bybit через дату самой старой дневной свечи (запрос до 1000
   дневных баров). Если монете меньше 182 дней — сигналы по ней
   не публикуются. Результат кэшируется в памяти на весь процесс,
   т.к. дата листинга не меняется.

3. ПОДТВЕРЖДЕНИЕ 3 ЗЕЛЁНЫХ СВЕЧЕЙ НА 30-МИНУТНОМ ТФ
   Новая функция three_green_30m(symbol) проверяет, что три
   последние ЗАКРЫТЫЕ 30-минутные свечи подряд зелёные (close > open).
   Это обязательное условие перед отправкой:
   - обычного 🟢 ЛОНГ-сигнала (long_ok)
   - раннего 🟠 РАННЕГО ЛОНГ-сигнала (long_ok_fast)
   Включается/выключается флагом REQUIRE_3_GREEN_30M = True.

Как настроить (переменные в начале файла):
- MIN_TURNOVER_24H       → порог оборота в USD (сейчас 30 млн)
- MIN_LISTING_AGE_DAYS   → порог возраста в днях (сейчас 182 = полгода)
- REQUIRE_3_GREEN_30M    → True/False, включить/выключить проверку свечей

Важно:
- Проверка возраста листинга делает дополнительный запрос к Bybit
  (дневные свечи) для каждой монеты, прошедшей базовые фильтры —
  это немного замедляет скан, но результат кэшируется, повторных
  запросов по той же монете не будет.
- Проверка 3 зелёных свечей делает отдельный запрос 30м свечей
  только для монет, которые уже прошли long_ok / long_ok_fast —
  минимальное влияние на скорость.
- Треугольник (ТРЕУГОЛЬНИК) и ранний сигнал по сжатию (🔵 РАННИЙ СИГНАЛ)
  автоматически защищены фильтрами оборота и возраста листинга,
  т.к. эти проверки стоят раньше в цикле сканирования — то есть
  все типы сигналов теперь идут только по монетам старше полугода
  и с оборотом от 30 млн $.

Как установить:
1. Замени файл бота на сервере на inflow_scanner_v7_filters.py
2. Переменные окружения не меняются.
3. Перезапусти процесс бота.
