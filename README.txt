БОТ v5 — ИСПРАВЛЕН ТРЕУГОЛЬНИК (15м, 3+ касания)
===================================================

Что изменилось по сравнению с v4:

1. detect_triangle() теперь ПРОВЕРЯЕТ реальное количество касаний
   каждой линии (сопротивления и поддержки). Раньше проходило
   даже при 2 точках на линию — теперь требуется минимум 3
   (константа MIN_TRIANGLE_TOUCHES = 3 в начале файла).

2. Добавлена новая функция detect_triangle_mtf(sym), которая
   реально запрашивает у Bybit СВЕЧИ 15-МИНУТНОГО, часового
   и 4-часового таймфрейма и считает треугольник на каждом.
   Раньше поле tri_mtf никогда не заполнялось, и блок
   "Треугольник по ТФ: 15м/1ч/4ч" в карточке был мёртвым кодом.

3. В run_scan() сигнал ТРЕУГОЛЬНИК теперь публикуется ТОЛЬКО
   если паттерн подтверждён именно на 15-минутном таймфрейме
   (tri_mtf["15м"] in ("ready","breakout")). Это соответствует
   требованию: "треугольник должен быть на 15-минутном ТФ с
   тремя касаниями".

4. Карточка сигнала теперь пишет "ТРЕУГОЛЬНИК" заглавными буквами
   и явно показывает, подтверждён ли паттерн на 15м.

Как установить:
1. Замени файл бота на сервере (Railway/VPS) на inflow_scanner_v5_triangle15m.py
2. Переменные окружения (TG_TOKEN и пр.) не меняются.
3. Перезапусти процесс бота.

Важно: детектор треугольника теперь делает больше запросов к Bybit API
(отдельно 15м/1ч/4ч свечи для каждой монеты с найденным треугольником),
поэтому скан может идти немного медленнее при большом числе монет.
