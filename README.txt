ИНСТРУКЦИЯ ПО УСТАНОВКЕ
========================

В этом архиве один файл — inflow_scanner_v4_full.py.
Это ПОЛНАЯ версия бота со строгой проверкой структуры треугольника:
- сопротивление строится только по >= 3 касаниям (было 2);
- касания должны быть разнесены по времени (не сгруппированы в одном месте);
- фигура не признаётся, если цена уже пробивала уровень раньше;
- обязательное сужение линий (convergence) — иначе это канал/флэт, а не треугольник;
- поддержка — строго растущие минимумы (>=2 точки);
- ATR-стоп, подтверждение объёма на пробое, prior_trend_up, защита от погони за ценой.

Старые отдельные файлы (triangle_v2.py, btc_phase.py, patch_btc_phase.py)
из более ранних версий переписки НЕ НУЖНЫ — вся их логика уже перенесена
внутрь inflow_scanner_v4_full.py. Не подключай их отдельно.

КАК ПОСТАВИТЬ:
1. Скачай inflow_scanner_v4_full.py из этого архива.
2. Замени этим файлом старый файл на сервере целиком (полная замена).
3. Переменные окружения (TG_TOKEN, TRADES_FILE, SIGNALS_FILE и т.д.)
   не трогай — они не менялись.
4. Перезапусти процесс/деплой.
5. Проверь через /scan — карточка треугольника теперь должна появляться
   только там, где реально видно фигуру с 3 касаниями сверху и растущими
   минимумами снизу.
